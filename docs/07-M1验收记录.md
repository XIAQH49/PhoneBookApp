## 3. 过程中解决的关键设备问题（沉淀）

| 问题 | 结论 |
|---|---|
| PLACE_CALL 受限权限不可获得（9568289） | 方案改为 want 唤起系统拨号应用，零权限（v0.3） |
| `ohos.want.action.dial` 无人注册 | 设备实测拨号入口 = `ohos.want.action.viewData` + `scheme=tel` + `entity.system.home`（v0.3.3） |
| `queryAbilityByWant` 预检静默失败 | 该 API 需 GET_BUNDLE_INFO 权限且已废弃 → 移除预检，直接 startAbility 按候选顺序尝试（v0.3.3） |
| CLI 签名不可用 | IDE 加密口令无法由 hvigorw 解密 → 签名安装统一走 IDE Run |
| ArkUI 子组件普通参数不随父状态更新 | StatBar/FilterChips 改 @Prop |
| 冷启动 DB 异步就绪竞态 | DbHelper 增加 ready()/失败可重试 + 页面延迟重试 + @State hasData |
| 换文件后责任人失效（v0.3.4） | 导入后检测当前责任人是否存在于新数据集，不存在自动回退到新数据第一个责任人并持久化；空态文案区分"未导入"与"当前责任人无数据"（真机复验通过 ✅） |
