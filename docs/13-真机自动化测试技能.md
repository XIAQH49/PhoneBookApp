# SKILL：HarmonyOS 真机自动化验证（hdc + uitest + 驱动 CLI）

> 用途：让任意 AI（或脚本）像本项目开发会话一样，通过 USB 操作真机、读取界面、
> 验证/回归应用功能，无需多模态能力。本文档 = 技能说明；执行器 = tools/device/drive.mjs。

---

## 1. 核心思想（先理解再看命令）

- **眼睛 = 控件树文本**：`uitest dumpLayout` 导出当前窗口的控件树 JSON（每个元素的 text/type/checked/bounds），
  拉回本地解析后就是"文本版截图"——定位元素（find）→ 算中心坐标 → 注入点击（tap）→ 再抓布局断言状态；
- **手 = hdc uinput 注入触摸**：点击/滑动/长按都只是坐标事件，与真手指等效；
- **证据 = 断言文本与状态**：统计数字变化、复选框 checked、徽标文案都是可断言的控件树内容；
- **边界**：Toast、系统弹窗（promptAction）、文件保存选择器、拨号盘是独立窗口，dumpLayout 抓不到——
  改用 `missions`（前台任务）判断"选择器/拨号盘是否唤起"，最终内容核对交给用户目视。

## 2. 前置条件

| 项 | 值 |
|---|---|
| hdc | D:\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe（可用环境变量 HDC 覆盖） |
| Node | D:\nodejs\node.exe |
| 设备 | SGT-AL10（HarmonyOS 7.0.0.102 log，平板 1320×2848）；需 USB 连接 + 屏幕解锁（人脸锁必须用户在场） |
| 安装 | 签名只能 DevEco Studio Run（CLI 无法解密签名口令；hdc install unsigned 会被拒 no signature file） |
| 坐标 | 先 layout 再 tap，**绝不硬编码坐标**（不同页面/数据量会移位） |

## 3. 命令速查（node tools/device/drive.mjs）

```
status                      # 设备是否在线
wake                        # 唤醒屏幕（解锁需用户；人脸锁会触发识别）
launch [bundle] [ability]   # 拉起应用（默认本应用）
kill [bundle]               # 强杀（持久化测试：改状态→kill→launch→断言保持）
layout [outFile]            # 抓控件树（默认 m2_layout.json），打印全部文本元素+坐标
texts <file>                # 打印布局文本清单（含中心坐标）
find <file> <text>          # 按文本找元素 → 输出 bounds 与 center（点击目标）
tap <x> <y>                 # 点击坐标
swipe <x1> <y1> <x2> <y2> [ms]  # 滑动（侧滑返回：x1=10, x2=700, ms=200）
missions                    # 前台任务（判断文件选择器/拨号盘是否唤起）
installInfo [bundle]        # updateTime（判断用户是否已 Run 新包）
screenshot [file]           # 截屏（仅对可读图模型有用；控件树才是默认眼睛）
```

原始命令对应关系：layout=uitest dumpLayout+file recv；tap/swipe=uinput -T -c/-m；
missions=aa dump --all；installInfo=bm dump -n；kill=aa force-stop。

## 4. 标准回归剧本（照抄即可）

```
# 1) 确认设备与新包
node tools/device/drive.mjs status
node tools/device/drive.mjs installInfo          # updateTime 变化=已装新包
# 2) 启动并抓主页
node tools/device/drive.mjs launch
node tools/device/drive.mjs layout m2_home.json
# 3) 定位并点击（例：设置齿轮）
node tools/device/drive.mjs find m2_home.json ' ⚙'   # 取 center.x/y
node tools/device/drive.mjs tap 1225 212
# 4) 断言到达设置页
node tools/device/drive.mjs layout m2_settings.json
node tools/device/drive.mjs texts m2_settings.json   # 应含 设置/拨号前确认/一键清除名单
# 5) 返回并断言回主页（Navigation pop→宿主刷新链路）
node tools/device/drive.mjs find m2_settings.json '← 返回'
node tools/device/drive.mjs tap 142 206
node tools/device/drive.mjs layout m2_home2.json
node tools/device/drive.mjs texts m2_home2.json       # 应含 外呼名单 + 统计数字
```

## 5. 关键断言技巧（本会话实战沉淀）

- **复选框状态**：布局 JSON 中 type=Checkbox 的元素带 checked 属性（"true"/"false"），直接断言；
- **统计/徽标**：断言文本（如 `已打 3`、`✓ 已打`、`完成 12%`）；
- **持久化**：改状态 → `kill` → `launch` → 再进页面断言状态保持；
- **侧滑返回手势**：`swipe 10 1400 700 1400 200`（左缘右滑），再断言回到上一页；
- **拨号唤起**：tap 拨打 → `missions` 里出现 com.ohos.contacts 前台即唤起成功，号码正确性由布局文本（199 1000 0003）断言；
- **保存选择器**：tap 导出 → `missions` 里 FilePickerUIExtAbility state #FOREGROUND 即弹出，文件名/保存/PC 核对交用户；
- **列表重复检测**：抓列表页 texts，按行切片比较相邻行姓名/工号是否相同；
- **安装时序**：用户"已 Run"后先看 installInfo 的 updateTime 是否变新，再 launch（老包数据会误导结论）。

## 6. 已踩过的坑（必须遵守）

1. 锁屏状态下 aa start 报 10106102；先 wake + 上滑（swipe 660 2820 660 500 150），人脸锁则必须用户解锁；
2. dumpLayout 只抓应用主窗口；Toast/系统弹窗/选择器/拨号盘抓不到——用 missions + 用户目视兜底；
3. 本设备上应用自定义 hilog 域不出现在 hdc shell hilog 流（现象未解）——诊断以 UI 行为证据为准，别浪费时间找日志；
4. uinput 语法：点击 -T -c x y；滑动 -T -m x1 y1 x2 y2 [smoothMs]（误用 -S 会报 invalid coordinate）；
5. 每步操作后要 Start-Sleep 2~4 秒再抓布局（页面切换/数据加载需要时间）；
6. 用户在设备上操作（打电话/微信）时立即停止注入触摸，避免误触；
7. 布局 JSON 每次 dump 文件名不同（layout_xxx.json），drive.mjs 已自动处理；
8. PowerShell 环境跑 drive.mjs 用 `& 'D:\nodejs\node.exe' tools\device\drive.mjs ...`（pwsh 内不要嵌套 pwsh）。
