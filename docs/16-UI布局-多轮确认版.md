## 一、信息架构（单页，用户拍板）

1. **顶栏**（照抄运动健康）：左「外呼名单」大标题（对应健康"今日"）；右侧**三个圆形图标按钮**——**搜索 / 更多 / 设置**，icon 全部换成运动健康样式。（已确认：去掉重复的"全部▾"，标题不再塞"张三⌄"）
2. **统计大卡**：左 已打大数字 + /分母；右 完成率圆环；三等栏 已打 / 未打 / 完成率；**底部一行「当前责任人：张三 ▾」点击进责任人选择**（已确认，替代顶栏责任人入口）。只保留一行总结合并（去掉重复的"全部责任人"行）。
3. **搜索**：点顶栏"搜索"按钮 → 统计卡下方**滑入圆角搜索输入行**，输入即过滤，再点收起（已确认）。
4. **筛选**：点顶栏"更多"按钮 → 弹出**筛选菜单：全部 / 未打 / 已打**，选中高亮（已确认，更多=只做筛选）。
5. **名单列表**：**单列宽卡**（已确认，非双列）。卡内容见 2.6。
6. **底部操作栏**：**运动健康样式悬浮胶囊**，保留四个功能：导入名单 / 内置名单 / 导出原始文件 / 导出结果（已确认，icon 运动健康样式）。
7. **详情页**：分区卡片——头部卡（姓名+号码+拨打主按钮）/ 状态卡（已打/打通/有意向 三行开关）/ 信息卡（责任人/工号/备注等其余列）。
8. **设置页**：分组卡片——拨号（拨号前确认/去除+86 开关）/ 导出（范围单选）/ 信息（数据条数·最近导入）/ 危险（一键清除名单）。

## 二、设计令牌与组件（沿用 docs/15，本文件仅定布局差异）

- **列表=单列宽卡**：内容限宽建议 `maxWidth=1040vp`（平板防横向拉长）；卡高 ~190vp、padding 20vp；
- **状态胶囊语义色**（已确认推荐）：已打=绿 success #19B46B / 未打=橙 warning #F59E0B / 打通=蓝 primary #0A84FF / 有意向=紫 #7657D9；
- **更多按钮=筛选菜单**：不再用页内 FilterChips 常驻行，筛选收纳进"更多"；
- **统计卡改为单行总结**：只留「当前责任人：张三 ▾ · 共20条」（去掉"全部责任人"第二行，或仅在切到"全部责任人"时显示）。
- 其余令牌/圆角/间距/字号/阴影/动效：全部沿用 docs/15（见其 1~5 节），此处不重复。

## 三、第 4 轮微调项（默认推荐，可改）

| 项 | 默认（已冻结） | 可改 |
|---|---|---|
| 名单卡内容 | 姓名+状态胶囊(右上) / 号码(主) / 工号+圆形拨号钮(右下)；多号码显示"手机 ×N"；卡片点击进详情、拨号钮独立不跳详情 | 若要在卡上加"打通/有意向"小徽标可告诉我 |

## 四、动效（沿用 docs/15 第 5 节）
- 卡片=normal-surface（克制）/ 统计卡=featured-surface / 底部胶囊=floating-tool / 状态胶囊·筛选选中=selection / 主操作=primary-action；
- 列表进入：springMotion(0.42,0.84)+错峰 i*35ms；状态胶囊切换 springMotion(0.30,0.80)；
- 搜索行展开：transition 滑入；筛选菜单：transition 弹出；底部胶囊按压 responsiveSpringMotion(0.18,0.82,0.06)；
- 圆环进度 springMotion(0.65,0.86)；详情转场 TransitionEffect.OPACITY(translate 24vp, scale 0.985)。
