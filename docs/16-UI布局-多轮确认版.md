## 一、信息架构（单页，用户拍板）

1. **顶栏**（照抄运动健康）：左「外呼名单」大标题（对应健康"今日"）；右侧**三个圆形图标按钮**——**搜索 / 更多 / 设置**，icon 全部换成运动健康样式。（已确认：去掉重复的"全部▾"，标题不再塞"张三⌄"）
2. **统计大卡**：左 已打大数字 + /分母；右 完成率圆环；三等栏 已打 / 未打 / 完成率；**底部一行「当前责任人：张三 ▾」点击进责任人选择**（已确认，替代顶栏责任人入口）。只保留一行总结合并（去掉重复的"全部责任人"行）。
3. **搜索**：点顶栏"搜索"按钮 → 统计卡下方**滑入圆角搜索输入行**，输入即过滤，再点收起（已确认）。
4. **筛选**：点顶栏"更多"按钮 → 弹出**筛选菜单：全部 / 未打 / 已打**，选中高亮（已确认，更多=只做筛选）。
5. **名单列表**：**单列宽卡**（已确认，非双列）。卡内容见 2.6。
6. **底部操作栏**：**运动健康样式悬浮胶囊**，保留四个功能：导入名单 / 内置名单 / 导出原始文件 / 导出结果（已确认，icon 运动健康样式）。
7. **详情页**：分区卡片——头部卡（姓名+号码+拨打主按钮）/ 状态卡（已打/打通/有意向 三行开关）/ 信息卡（责任人/工号/备注等其余列）。
8. **设置页**：分组卡片——拨号（拨号前确认/去除+86 开关）/ 导出（范围单选）/ 信息（数据条数·最近导入）/ 危险（一键清除名单）。

## 六、沉浸光感与滚动流畅增强（用户追加，2026-08-27）

> 覆盖并修正 docs/15 校对 #6（Header 不做毛玻璃）与 GPT 建议——用户明确**顶栏也要毛玻璃**。

### 6.1 顶栏沉浸光感毛玻璃（非纯色）

- 顶栏（标题 + 搜索/更多/设置三圆钮）固定于顶部，**滚动时内容从其下方穿过，顶栏显示毛玻璃而非纯色**。
- 实现（2026-08-29 修订：真机实证 `backgroundBlurStyle` 系统材质在本层级仅渲染遮罩色——"变暗变灰"无模糊感；换**真实背景高斯模糊滤镜**）：
  - `.backdropBlur(26)`（模糊"背后内容"，前景文字/图标不受影响；半径甜蜜点 15~35，26 居中）+ `.backgroundColor(表面色 @ 0.28 半透明，bar_bg #47FFFFFF/#471A1D21)`（alpha 0.15~0.25 为宜，太高把模糊洗成灰底）+ `.shadow` 悬浮光感阴影 + 顶缘反射光带（白 0.42→0 渐变 12vp，模拟环境光反射）+ 高光描边。
  - 内容用 Stack 叠层——顶栏在上、Scroll 内容在下（参考 docs/15 6.3 的 Stack>Scroll 结构，把 Header 移出 Scroll 置为顶层覆盖）。
- 深浅色：深色下 blur 底色换深色半透明，毛玻璃层次不丢失。
- 注意：毛玻璃只用于顶栏与底部胶囊这两个浮层；浮层之外内容不 blur，避免滚动掉帧（docs/15 6.2 原则保留）。

### 6.2 沉浸式状态栏 / 导航栏（无白边/黑边）

- 内容延伸至系统状态栏与导航栏之下（edge-to-edge），系统栏**透明**，图标颜色随深/浅色切换，**不要白边/黑边**。
- 入门关键（API 26 已实测可用）：
  - EntryAbility onWindowStageCreate：取主窗口 window.getMainWindowSync() → setWindowLayoutFullScreen(true)（内容铺满）；
  - setWindowSystemBarProperties({ statusBarColor:#00000000, navigationBarColor:#00000000, statusBarContentColor:isDark?#FFFFFF:#000000, navigationBarContentColor:isDark?#FFFFFF:#000000 })（透明 + 图标自适应）；
  - 根组件 .expandSafeArea([SafeAreaType.SYSTEM], [SafeAreaEdge.TOP, SafeAreaEdge.BOTTOM])。
- 内容安全区：顶栏 paddingTop = 状态栏高度；列表 bottom 预留 = 导航栏 + 底部胶囊 + 32vp（getWindowAvoidArea 或系统安全区常量）。
- 深浅色切换时同步更新系统栏图标颜色（onConfigurationUpdate / 监听系统深色变化）。

### 6.3 名单列表上滑渲染流畅（预渲染，不"滑到第 3 个才露第 3 个"）

- **用 cachedCount 预渲染**：Grid/List 设 .cachedCount(10)（或 { leading:8, trailing:12 } 更精细），让滚动方向上尚未到达的条目**提前构建好**，到达即显示、无"第 3 个弹出"卡顿。
- **卡片定高**：PersonCard 固定高度（190vp），避免动态高度导致 LazyForEach 尺寸估算偏差与反复重排——预估才能提前渲染。
- **LazyForEach key 稳定**：用 row.id（勿用 index / JSON.stringify / dataVersion 不停升版）；dataVersion 只在数据真正变化时递增；滚动加载更多用 notifyAdd + cachedCount，不要每次滚动都版本号全量重建。
- **构建轻量化**：号码显示串、"手机×N"、状态文案在进 model/视图模型时算好，不在 item builder 里每帧算；item builder 只做布局与绑定。
- **滚动条**：.scrollBar(BarState.Off) 或 Auto，配合 .scrollBarColor(半透明主色) 避免抖动。
- **异步加载节奏**：loadMore 用 onReachEnd；加载中显示轻量占位（骨架或保持旧条目），避免列表"跳"。
