## 3. M2 处置细节

### 3.1 W-3 包装模式（database 层四文件）

- 每个 DAO 方法内：SDK 调用统一 try/catch，失败 Logger.error + `throw new Error('方法名 failed: ...')`；
- ResultSet 生命周期统一 finally 中 try/close（关闭失败忽略），避免游标泄漏且不遮蔽主异常；
- rowToRecord/rowToMeta 整体包装（内部 JSON.parse 仍保持原"解析失败取默认值"语义）；
- 事务/回滚/双写逻辑与异常传播路径不变（DbHelper.runInTransaction 原样保留）。

### 3.2 W-1 Navigation 迁移要点

- Index 为导航宿主：`Navigation(this.pathStack)` + `@Builder pageMap` + `.navDestination`，子页改 NavDestination（去掉 @Entry，main_pages.json 仅保留 pages/Index）；
- 传参：`pushPathByName(name, param, onPop)`；子页 `onReady(ctx)` 取 `pathInfo.param` 与 `pathStack`；
- 返回：子页统一 `pop(result)` 并 `onBackPressed` 拦截系统返回（返回 true），保证宿主 onPop 回调必然触发 → `onSubPageReturn()` 重载责任人视图与统计；
- 详情页拨号后标记：由"返回页面生命周期回调"改为"唤起拨号即标记"（R-7 拨出即算已打，语义等价且更健壮）。

### 3.3 W-2 新 API 行为说明

- `util.TextDecoder.decode` → `decodeToString`：同步返回 string；空输入按新 API 文档可能返回 undefined，调用处兜底返回空串；
- 编码检测链路不变：BOM → utf-8；无 BOM 严格 utf-8（fatal）失败回退 gbk（fatal=false）。
