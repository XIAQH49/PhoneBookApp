### 1.1 关键决策（用户拍板 + 新稿）

- **双列恢复**：用户先拍板单列（v0.1.2），后引入 ChatGPT 设计稿并确认「按新稿恢复双列」（≥360vp 双列/<360vp 单列）——最终以此为准；
- 底部为操作按钮栏（非多页 Tab）；Header 不做毛玻璃（校对#6），毛玻璃只给 BottomActionBar（6.2）；
- PersonCard 不每卡发光（别做清单#1：光感只在 StatCard/FloatingBar/PrimaryAction/Selection）；
- 数据模型/DAO/服务层零改动；LazyForEach 键保留 `id_version` 模式（6.5 的纯 row.id 建议会回归 M2 已修 bug，未采纳——沿用数据源版本号并入键的既有修复）。

### 1.2 真机实测坑位（新增，已修，commit c34cd0e）

- **@Builder 传参固化**：@Builder 函数带参数调用时，参数值在首次渲染固化、父组件 build 重跑不重算——
  表现：标记后大数字/圆环更新但三等栏与计数胶囊不刷新（与早前 200/26/88% 异常同源）。
  修复：所有动态值一律**无参 @Builder 直读 this**（StatCard 三指标/FilterChips 计数/BottomActionBar 四按钮/详情三状态行/设置开关与单选行），组件内已加注释警示；
- Switch（ToggleType.Switch）无 `.unselectedColor()` 链式方法（SDK 查证仅有 selectedColor），回退默认轨道色。
