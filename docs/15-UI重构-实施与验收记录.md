### 7.5 官方沉浸光感文档适配（用户指定，本机 SDK 26 实证）

官方文档：
- [沉浸光感-UI开发 (ArkTS声明式开发范式)](https://developer.huawei.com/consumer/cn/doc/HarmonyOS-Guides/arkts-immersive-light-sense)
- [沉浸光感常见问题（FAQ）](https://device.harmonyos.com/cn/docs/apiref/harmonyos-guides/arkts-immersive-light-sense-faq)

**官方组件 API（API 26 `@ohos.arkui.uiMaterial`）**：`ImmersiveMaterial`/`ImmersiveOptions`（style 厚度 ULTRA_THIN~ULTRA_THICK、materialColor、colorInvert、applyShadow 材质阴影、interactive、**lightEffect 光效交互反馈=官方"光随指动"**）+ `Material.empty`（禁用）+ `getMaterialInfo()`（应用配置）。
**本机 SDK 实证**：普通容器组件（Row/Column/Stack/Grid）的沉浸材质属性**未公开**，`ImmersiveMaterial` 仅出现于 Tabs/系统弹窗（systemMaterial 生态）→ 无法直接落码组件属性；**等效落地**：
1. **门控（本版本实施）**：`ThemeSpec.initImmersiveGate()` 读取 `getMaterialInfo()`——系统沉浸关闭（MaterialState.DISABLE）时毛玻璃/光效自动降级（顶栏/底栏纯色、光线条数系数 0、边框加粗表达层次），读取异常回退启用（fail-safe）；EntryAbility.onCreate 页面加载前调用；
2. 光随指动/光线勾勒/非线性形变：以 docs/15 四节语义材质（interpolatingSpring 按压 + 边缘高光 + 弹性曲线）等效实现；
3. **FAQ 四项与本版本方案对照**（均已修复并真机验证）：①深色模式状态栏图标看不清 → onConfigurationUpdate 同步内容色；②挂起/退出顶部闪现白条 → start_window_background 双套=页面同色；③跳转页面后未避让状态栏 → 内容层保持系统避让；④页面与导航条区域色调不一致 → 状态栏底色=页面同色（不设导航栏属性，避免强制弹出导航条产生白边）。

### 7.6 毛玻璃/渲染修复（用户真机两项反馈，2026-08-28 晚）

| 反馈 | 根因 | 修复 |
|---|---|---|
| 浮层无毛玻璃、背景纯色 | COMPONENT_ULTRA_THICK 在此设备观感=纯色；且内容层底部预留 76+32+48vp 空白带+顶栏静止时下方无内容滑过 → 模糊没有可透内容 | ①换系统背景语义最厚档 `BlurStyle.BACKGROUND_ULTRA_THICK`；②bar_bg 0.82→0.55（底层可透出）；③Grid 底部预留→48vp（内容可滚动穿过底栏，模糊真实可见、无遮挡感空白带） |
| 名单卡片"滑到才渲染/弹入"，像被底栏遮挡 | cachedCount 预建后的卡片每次 aboutToAppear 重播入场动画（opacity 0→1） | 入场动画仅首屏播放（PersonCard.animateIn 门控，Index 900ms 后置 false；之后新建卡片直接显示） |

**验证（226 行真实名单，SGT-AL10）**：上滑流畅；翟浩卡内容延伸至 y2657 > 底栏上缘 y2490（内容从底栏下穿过）；像素采样顶栏 #CCCCCC / 底栏 #CECFD1（内容与 0.55 白+模糊混合，非纯白）——毛玻璃真实可见。

### 7.7 毛玻璃二修——真实背景高斯模糊（用户反馈"只是变暗变灰，没有透明反射"，2026-08-29）

| 反馈 | 根因 | 修复 |
|---|---|---|
| 浮层"只是变暗了、变灰了，没有透明，没有反射，完全不是毛玻璃" | `backgroundBlurStyle(BlurStyle.BACKGROUND_ULTRA_THICK)` 系**系统预置磨砂材质**，在本层级只渲染了材质遮罩色（≈0.55 白叠层），模糊采样未真正生效；且 bar_bg 0.55 透明度过高，把底层内容完全洗淡 | ①换**真实背景高斯模糊滤镜** `.backdropBlur(26)`（模糊"背后内容"、前景清晰；与 `.blur()` 模糊"自身内容"本质不同，二者不可混用）；②bar_bg 0.55→**0.28**（#47FFFFFF / #471A1D21，甜蜜点 0.15~0.25，保留背后内容辨识度）；③底部光带 3px→**12vp 玻璃顶缘反射带**（REFLECT_COLOR 白 0.42→0 渐变，模拟环境光反射，与玻璃同圆角） |

**实现要点**：毛玻璃 = 半透明底（玻璃本体）+ backdropBlur（背后内容模糊）+ 顶缘反射（反射）+ 高光描边/光感阴影（立体）三层；`backgroundBlurStyle` 系统材质在此层级不产生可感知模糊（实测证据：换滤镜前像素采样为平坦灰白）。

### 7.8 责任人选择页选中行撑大（用户反馈"选中的变得巨大，未选中的正常"，2026-08-29）

| 反馈 | 根因 | 修复 |
|---|---|---|
| 选择责任人页：当前选中行巨大（约 386vp 高），其余行正常（约 80vp） | 选中指示条 `Row().height('60%')` 的**百分比高度**——ListItem 内父容器高度未确定时，60% 被解析为 List 可用空间的 60%（≈1300px），把选中行撑成 4.8 倍高（像素采样：选中行浅蓝背景 y684→1988，其他行间隔仅 271px） | 改固定 `height(24)` + 行内垂直居中；全项目复查 `height('%')` 仅此一处（其余 `height('100%')`/`width('100%')` 父容器明确，安全） |

### 7.9 空态页去重（用户反馈"导入按钮已被收编到底部操作栏"，2026-08-29）

| 反馈 | 根因 | 修复 |

### 1.1 关键决策（用户拍板 + 新稿 + 反馈）

- **单列/双列**：用户先拍板单列（v0.1.2）→ ChatGPT 稿恢复双列 → 第二轮反馈因姓名截断改回**固定单列**（最终形态）；
- 底部为操作按钮栏（非多页 Tab）；毛玻璃只给顶部栏与 BottomActionBar 浮层（不给卡片——别做清单#1 与 6.2）；
- PersonCard 不每卡发光；光感档位按反馈固定 high；
- 数据模型/DAO/服务层零改动；LazyForEach 键保留 `id_version` 模式（6.5 的纯 row.id 建议会回归 M2 已修 bug，未采纳——沿用数据源版本号并入键的既有修复）。

### 1.2 真机实测坑位（新增，已修，commit c34cd0e）

- **@Builder 传参固化**：@Builder 函数带参数调用时，参数值在首次渲染固化、父组件 build 重跑不重算——
  表现：标记后大数字/圆环更新但三等栏与计数胶囊不刷新（与早前 200/26/88% 异常同源）。
  修复：所有动态值一律**无参 @Builder 直读 this**（StatCard 三指标/底部栏四按钮/详情三状态行/设置开关与单选行），组件内已加注释警示；
- Switch（ToggleType.Switch）无 `.unselectedColor()` 链式方法（SDK 查证仅有 selectedColor），回退默认轨道色。
