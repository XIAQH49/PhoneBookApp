# PhoneBookApp 构建与真机调试指引

本机环境实测信息（供命令行构建与真机验证使用）：

| 项 | 路径/值 |
|---|---|
| DevEco Studio | `D:\DevEco Studio` |
| HarmonyOS SDK | `D:\DevEco Studio\sdk`（env: `DEVECO_SDK_HOME`） |
| hvigor CLI | `D:\DevEco Studio\tools\hvigor\bin\hvigorw.js`（用 `D:\DevEco Studio\tools\node\node.exe` 执行） |
| ohpm | `D:\DevEco Studio\tools\ohpm\bin\ohpm.bat` |
| 系统 Node | `D:\nodejs\node.exe`（v26，用于 tools/verify 纯逻辑验证） |

---

## 1. 命令行构建（编译验证门禁）

```powershell
# 在工程根目录 D:\DevecoStudioProjects\PhoneBookApp 下执行：
$env:DEVECO_SDK_HOME = 'D:\DevEco Studio\sdk'
& 'D:\DevEco Studio\tools\node\node.exe' 'D:\DevEco Studio\tools\hvigor\bin\hvigorw.js' `
  assembleHap --mode module -p product=default -p buildMode=debug --no-daemon
```

- 产物：`entry/build/default/outputs/default/entry-default-unsigned.hap`
- 注意：首次 CLI 构建会初始化 `~/.hvigor/project_caches/<hash>/workspace`，
  若报 `ENOENT ... @ohos\hvigor\bin\hvigor.js`，删除对应 workspace 目录后重试即可（本机已自愈）。
- **hvigor 每次运行都需要对 `~/.hvigor` 目录的写入权限**（缓存校验/依赖安装）。
  若在受限沙箱/低权限会话中执行，会出现上述 ENOENT 或安装失败的假象——请在正常用户会话或放开 `~/.hvigor` 写权限的环境中执行。

## 2. 纯逻辑快速验证（不依赖 IDE）

```powershell
node --import ./tools/verify/register.mjs tools/verify/verify.ts
```

覆盖 FR-9 号码解析、FR-2 合并/状态取或、已打值判定与格式探测、CSV 编码检测/解析/写出、导入列识别（与 hypium 单测同源）。

## 3. 真机安装与调试

1. 手机开启开发者模式，USB 连接，命令行确认：`hdc list targets`（`D:\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe`）；
2. 安装 HAP：`hdc install entry/build/default/outputs/default/entry-default-unsigned.hap`
   （未签名包安装到真机需先 `hdc shell param set const.product.hmos.signature.enable false`? 视版本而定；
   更稳妥的方式是 DevEco Studio 里配置自动签名后 Run）；
3. 日志：`hdc shell hilog | findstr PhoneBook`。

## 4. 权限说明（v0.3：无需任何权限）

- 拨号采用 want `ACTION_DIAL`（ohos.want.action.dial）+ `tel:` URI 唤起系统拨号应用，
  **不申请 PLACE_CALL**（实测该受限权限不可获得：安装报 `code:9568289`），AGC 流程已取消；
- 文件选择走系统 picker，无存储权限；无网络权限；
- 若未来改回直接外呼（`call.makeCall`）才需要按 AGC 受限权限流程开通 PLACE_CALL。

## 5. 单测运行

- **LocalUnit（hypium）**：在 DevEco IDE 中右键 `entry/src/test` → Run 执行。
  ⚠️ CLI 的 `hvigorw test` 任务不解析对 `src/main/ets` 的导入（测试编译图不含主模块源码，实测确认），
  因此 **CLI 侧的逻辑验证以 `tools/verify` Node 套件为准（34 项，覆盖纯逻辑+CSV+xlsx 往返）**；
  hypium LocalUnit 用例与 Node 套件同源，供 IDE 内执行。
- **ohosTest（集成测试，需设备/模拟器）**：连接设备后在 IDE 运行 `entry/src/ohosTest`，
  覆盖数据库双写一致性、事务回滚（模拟器可跑，不依赖电话能力）。

## 6. 已知注意事项

- 模拟器不支持电话能力：FR-5 拨号链路与 T-3 spike 必须在真机验证；
- `local.properties` 由 DevEco 自动生成，不提交版本库（本项目未生成 sdk.dir，CLI 构建依赖 `DEVECO_SDK_HOME`）；
- **xlsx 支持**：ohpm 官方源无可用 xlsx 包，采用 vendor 方案——SheetJS 社区版（Apache-2.0）内置在
  `entry/src/main/ets/libs/xlsx.full.min.js`（类型声明与 LICENSE 同目录），功能面已由
  `tools/verify` 用同一库文件在 Node 完成往返验证；真机加载与性能见 `docs/06-真机验证清单.md` T-1。
