## 1. 设计语言（空间光感落地原则）

- **层次**：内容全部卡片化——浅底大圆角卡片 + 彩色光感阴影（主色调低透明度阴影）；
- **材质**：顶部栏与底部操作栏用毛玻璃（backgroundBlurStyle.Thick）悬浮于内容之上；
- **数字优先**：关键指标超大字号（对应参考页"3,895 /2,000 步"）；
- **圆与胶囊**：图标按钮一律圆形；筛选/状态一律胶囊；底部操作栏为悬浮胶囊；
- **留白**：组间距 >= 卡片间距 >= 卡片内边距（对应参考页 54/24~40/40px 的比例关系）；
- **动效**：弹簧/跟手为主、克制——同一时刻只动一处主视觉，时长 <= 400ms（参数见第 5 节）。

## 3. 组件规格

| 组件 | 规格 |
|---|---|
| IconButton（圆形图标按钮） | 48vp 圆形；主色浅底+主色图标；按压 scale 0.9 + brightness 0.85 |
| StatusPill（状态胶囊） | 高 28vp、全圆；✓已打=成功色浅底+深色字；●未打=警示色浅底；点击切换（标记/撤销） |
| FilterChips（筛选胶囊） | 高 36vp；未选中=卡片白底描边；选中=主色填充白字；切换带动效（见 5.4） |

| StatCard（统计大卡） | 全宽卡片；左=大数字+目标分母，右=ProgressRing；底部三等栏指标 |

## 5. 动效规格（基于本机 SDK 实测 API，参数可直接落码）

> 统一入口：实现时把动效参数集中到 common/MotionSpec.ets（曲线/时长/位移/缩放/模糊即取即用），便于真机截图微调。
> 以下曲线均为 HM 官方 API：springMotion / responsiveSpringMotion（API 9+）、interpolatingSpring（API 9+，跟手）、
> animateTo、transition、backgroundBlurStyle（API 9+）、motionPath、Particle。

### 5.1 弹性/跟手曲线（与参考页一致的灵动手感）

| 用途 | 曲线 | 说明 |
|---|---|---|
| 默认入场/出现 | responsiveSpringMotion() | 官方默认，响应式弹簧，跟手不拖泥带水 |
| 大卡/列表入场 | springMotion(0.35, 0.75) | 稍慢、柔和的弹入 |
| 按压跟手（列表行/卡片） | interpolatingSpring(velocity, 1, 180, 20) | 手速越高回弹越快；按压 scale 0.96 |
| 拨号/主按钮 | springMotion(0.28, 0.7) | 快速清脆的反馈 |

### 5.2 转场（页面级）

| 场景 | 实现 | 参数 |
|---|---|---|
| Navigation 子页 push/pop | 保留现有 NavPathStack 默认转场（避免返工） | — |
| 子页内容卡片错峰 | transition(TransitionEffect.OPACITY) + .animation 按 index*40ms delay | 详情分区卡、设置分组卡依次淡入 |
| 主机返回刷新 | 沿用 onPop 回调 + 延迟 400ms（v0.5.4 已修，勿动） | — |

### 5.3 列表/卡片动效

| 对象 | 效果 | 参数（改 common/MotionSpec.ets 即全局生效） |
|---|---|---|
| PersonCard 入场 | 淡入 + 上移 + 弹性 | opacity 0→1，translateY 20→0，springMotion(0.35,0.75)，stagger index*40ms |
| PersonCard 按压 | 反馈 | scale 0.96 + brightness 0.9，interpolatingSpring |
| StatusPill 切换 | 颜色/文字弹性过渡 | animateTo(springMotion(0.3,0.7)) { 背景/前景色 }，120ms |
| 搜索结果变化 | 高度重排动画 | LazyForEach 数据源版本键已触发重建 + 默认布局动画 |

### 5.4 统计卡与圆环

| 对象 | 效果 | 参数 |
|---|---|---|
| ProgressRing | 进度环弹性生长 | animateTo(springMotion(0.5,0.8)) { sweep 0→百分比 }，1200ms |
| 大数字 | 简化数字滚动（透明度+位移，不引第三方） | 旧 opacity 0→新 opacity 1，translateY 12→0，200ms |
| 三等栏 | 数值更新轻弹 | animateTo(springMotion(0.35,0.75)) |

### 5.5 底部操作栏（悬浮胶囊）

| 对象 | 效果 | 参数 |
|---|---|---|
| 悬浮 | Thick 毛玻璃 + shadow_raised | backgroundBlurStyle(BlurStyle.Thick)，随时悬浮于列表之上 |
| 按钮按压 | 弹性 | interpolatingSpring + scale 0.94 + brightness 0.9 |
| 点击后 | 触发动作（导入/内置/导出） | 单页架构无跳转，Toast 反馈 |

### 5.6 光感细节（可选增强，低风险，优先级后置）

- 卡片按压时 shadow 增强 + 微上移（shadow_raised 过渡）；
- 顶部毛玻璃栏随内容滚动做透明度层次过渡；
- 深色模式：颜色走 $r('app.color.*') 双套资源，主色微光阴影深色下 alpha 降至 0.05；
- 粒子（Particle）仅在"全部完成"庆祝态使用，其余不引（性能与克制原则）。

## 7. 验收与边界

- **功能等价回归**：导入(xlsx/csv)/筛选/搜索统计/唤起拨号/标记(已打+打通+意向)/导出/内置名单/一键清除/一键导出原始文件 全过（uitest 自动化 + 用户截图确认）；
- **视觉验收**：实现后真机截屏回填给用户目视确认（无需多模态 AI，用户即评审）；
- **构建门禁**：clean 0 错误 0 警告；verify 46/46 保持；
- **边界**：平板 vs 手机尺寸差异靠栅格；双列卡片窄屏降单列；毛玻璃低端机若掉帧可降为不透明白卡；
- **不做的**：不引入第三方动效库；不做多页 Tab；不改数据模型与业务逻辑。
