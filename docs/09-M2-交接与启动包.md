## 5. 关键坑位清单（新会话必读，避免重踩）

1. **签名**：CLI hvigor 无法解密 IDE 加密口令（`Init keystore failed`）；签名+安装统一走 **DevEco Studio Run**；
2. **CLI 测试限制**：`hvigorw test` 不解析 src/main 导入（测试编译图不含主模块）；CLI 逻辑验证以 tools/verify node 套件为准，hypium 仅 IDE 内跑；
3. **拨号**：无权限方案 = `startAbility(want viewData + tel:URI + entity.system.home)` 唤起 com.ohos.contacts 拨号盘（`action.dial` 无人注册；`queryAbilityByWant` 需权限且废弃，勿用预检）；
4. **ArkUI**：子组件参数必须 @Prop/@Link（普通参数不随父状态更新）；空态视图用 layoutWeight(1) 勿用 height(100%)（会挤出底部按钮栏）；
5. **冷启动**：DB 异步初始化需 `DbHelper.ready()` 等待 + 页面重试（见 DbHelper.initPromise）；
6. **合并语义**：文件内同键行全部保留（v0.5.3）；本地按同键队列一一匹配；状态取"或"；
7. **构建环境**：`DEVECO_SDK_HOME=D:\DevEco Studio\sdk`、`JAVA_HOME=D:\DevEco Studio\jbr`；构建目录 .hvigor/entry/build 勿提交（.gitignore 已覆盖）；
8. **rawfile/名单.xlsx**：本地构建用、已 gitignore；测试样本在 samples/。
